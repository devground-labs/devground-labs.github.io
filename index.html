Principles

How we build.

The rules every devground-labs app follows, so you know what you're installing.

Private by default

No analytics, no telemetry, no accounts. Your data stays on your Mac.

Open source

Every app is Apache 2.0 licensed. Read the code, build it yourself, or help improve it.

Native and fast

Small, compiled apps that launch instantly and respect light mode, dark mode and system fonts.

You stay in control

Apps explain and suggest. They don't make changes to your Mac without you.

Open source

Built in the open.

Every release is built from public source by GitHub Actions, so what you download is exactly what's in the repository. Issues, ideas and pull requests are welcome.
